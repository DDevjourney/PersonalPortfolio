# Modo oscuro Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Añadir un tema oscuro (fondo `#242424`) con un botón para alternar entre claro y oscuro, colocado abajo a la izquierda en escritorio y en la cabecera en móvil.

**Architecture:** Los tokens de color de Tailwind pasan a variables CSS (`rgb(var(--token) / <alpha-value>)`) definidas para `:root` (claro) y `:root[data-theme='dark']`. Un `ThemeProvider` con contexto guarda el tema en `localStorage` (o sigue `prefers-color-scheme`) y lo aplica como `data-theme` en `<html>`; un script inline en `index.html` lo aplica antes del primer pintado. Los hex fijos de los componentes se migran a los tokens.

**Tech Stack:** React 18, TypeScript, Vite 5, Tailwind CSS 3.4, `lucide-react` (iconos `Sun` / `Moon`).

**Nota sobre pruebas:** el proyecto no tiene test runner y el spec no lo pide. La verificación de cada tarea es `npm run build` (`tsc -b && vite build`) y, donde se indica, comprobación en el navegador con el servidor `portfolio` de `.claude/launch.json` (puerto 5183).

## Global Constraints

Copiado del spec `docs/superpowers/specs/2026-10-14-dark-mode-design.md`:

- Fondo oscuro: `paper` = `#242424`. Tema por defecto (sin atributo `data-theme`): claro.
- Tokens en formato `rgb(var(--token) / <alpha-value>)` para que sigan funcionando `border-ink/15`, `bg-paper/80`, etc.
- Clave de `localStorage`: `theme`, con valores `'light'` | `'dark'`. Toda lectura/escritura de `localStorage` va en `try/catch`.
- `<meta name="theme-color">`: `#E8E6E1` en claro, `#242424` en oscuro.
- Botón: `<button type="button">` con `aria-label` ("Cambiar a modo oscuro" / "Cambiar a modo claro"), icono `aria-hidden`, foco visible. Móvil: objetivo táctil de 44 px (`h-11 w-11`).
- Fuera de alcance: modo "sistema" explícito en la interfaz, versiones oscuras de capturas/favicon, cambios de contenido o estructura.
- Los comentarios del código van en español, igual que el resto del proyecto.

### Task 2: Lógica del tema (`ThemeProvider`, `useTheme`, script anti-parpadeo)

**Interfaces:**

- [ ] **Step 1: Crear `src/hooks/useTheme.tsx`**

```tsx
import { createContext, useCallback, useContext, useEffect, useMemo, useState } from 'react'
import type { ReactNode } from 'react'

export type Theme = 'light' | 'dark'

const STORAGE_KEY = 'theme'
const DARK_QUERY = '(prefers-color-scheme: dark)'
/** Color de la barra del navegador en móvil: el mismo `paper` de cada tema. */
const THEME_COLOR: Record<Theme, string> = { light: '#E8E6E1', dark: '#242424' }

/** Tema guardado por el usuario, o `null` si nunca ha elegido (o no hay storage). */
function readStored(): Theme | null {
  try {
    const value = localStorage.getItem(STORAGE_KEY)
    return value === 'light' || value === 'dark' ? value : null
  } catch {
    return null
  }
}

function writeStored(theme: Theme) {
  try {
    localStorage.setItem(STORAGE_KEY, theme)
  } catch {
    // Modo privado o storage bloqueado: la elección vale solo para esta visita.
  }
}

function systemTheme(): Theme {
  return window.matchMedia(DARK_QUERY).matches ? 'dark' : 'light'
}

interface ThemeContextValue {
  theme: Theme
  toggle: () => void
}

const ThemeContext = createContext<ThemeContextValue | null>(null)

/**
 * Tema de la web. Arranca con el guardado o, si no hay, con el del sistema, y
 * mientras el usuario no elija sigue los cambios del sistema. Lo aplica como
 * `data-theme` en <html> (las variables CSS de `index.css` hacen el resto). El
 * estado vive aquí, en un contexto, para que los dos botones (cabecera y
 * columna lateral) estén siempre sincronizados.
 *
 * El script inline de `index.html` aplica el mismo criterio antes del primer
 * pintado; este efecto solo confirma el valor y mantiene `theme-color`.
 */
export function ThemeProvider({ children }: { children: ReactNode }) {
  const [theme, setTheme] = useState<Theme>(() => readStored() ?? systemTheme())

  useEffect(() => {
    const mq = window.matchMedia(DARK_QUERY)
    const onChange = () => {
      if (readStored() === null) setTheme(mq.matches ? 'dark' : 'light')
    }
    mq.addEventListener('change', onChange)
    return () => mq.removeEventListener('change', onChange)
  }, [])

  useEffect(() => {
    document.documentElement.dataset.theme = theme
    document.querySelector('meta[name="theme-color"]')?.setAttribute('content', THEME_COLOR[theme])
  }, [theme])

  const toggle = useCallback(() => {
    const next: Theme = theme === 'dark' ? 'light' : 'dark'
    writeStored(next)
    setTheme(next)
  }, [theme])

  const value = useMemo(() => ({ theme, toggle }), [theme, toggle])

  return <ThemeContext.Provider value={value}>{children}</ThemeContext.Provider>
}

export default function useTheme() {
  const ctx = useContext(ThemeContext)
  if (!ctx) throw new Error('useTheme debe usarse dentro de <ThemeProvider>')
  return ctx
}
```

- [ ] **Step 1: Crear `src/components/ThemeToggle.tsx`**

```tsx
import { Moon, Sun } from 'lucide-react'
import useTheme from '../hooks/useTheme'

interface ThemeToggleProps {
  /** `icon`: solo icono (cabecera móvil). `labeled`: icono y texto (columna lateral). */
  variant: 'icon' | 'labeled'
}

/**
 * Alterna entre tema claro y oscuro. Muestra la acción, no el estado actual:
 * en claro ofrece "Oscuro" (luna) y en oscuro ofrece "Claro" (sol).
 */
export default function ThemeToggle({ variant }: ThemeToggleProps) {
  const { theme, toggle } = useTheme()
  const toDark = theme === 'light'
  const Icon = toDark ? Moon : Sun
  const label = toDark ? 'Oscuro' : 'Claro'
  const ariaLabel = toDark ? 'Cambiar a modo oscuro' : 'Cambiar a modo claro'

  if (variant === 'icon') {
    return (
      <button
        type="button"
        onClick={toggle}
        aria-label={ariaLabel}
        // h-11 w-11 lleva el objetivo táctil a 44px.
        className="flex h-11 w-11 items-center justify-center text-ink focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-ink"
      >
        <Icon aria-hidden size={20} />
      </button>
    )
  }

  return (
    <button
      type="button"
      onClick={toggle}
      aria-label={ariaLabel}
      className="flex h-11 items-center gap-2 font-mono text-sm uppercase tracking-wider text-ink focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-ink focus-visible:ring-offset-4 focus-visible:ring-offset-paper"
    >
      <Icon aria-hidden size={16} />
      <span className="underline decoration-accent decoration-2 underline-offset-8">{label}</span>
    </button>
  )
}
```
